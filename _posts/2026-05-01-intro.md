**Welcome to our tutorial on Wireless Digital Twins**.

This session will help you become familiar with two research-grade software packages that together support end-to-end wireless environment generation and simulation:

* Geo2SigMap — Environment and RF Map Generation
* Sionna-RT — Wireless Ray-Tracing and Simulation

**Descriptions of each software package can be found below:**

### [Geo2SigMap](https://github.com/functions-lab/geo2sigmap/tree/main)

Geo2SigMap is an efficient framework for high-fidelity RF signal mapping leveraging geographic databases, ray tracing, and a pretrained U-Net model. The project offers an automated and scalable pipeline that efficiently generates 3D building and path gain (PG) maps. The repository is split into two distinct partitions:

* Scene Generation: A Python-based pipeline for generating 3D scenes for arbitrary areas of interest.
* ML-based Propagation Model: ML-based signal coverage prediction using our pre-trained model based on the cascaded U-Net architecture described in [this paper](https://ieeexplore.ieee.org/document/10632773).

As of November 2025, v2.0.0 enhances the scene generation pipeline to include:

* LiDAR Terrain Data
* Building Height Calibration using Digital Elevation Models (DEMs)

This drastically improves the accuracy of the environment being processed by the ML-based Propagation Model or Wireless Ray Tracer.

### [Sionna-RT](https://github.com/NVlabs/sionna-rt)

Sionna-RT is a wireless ray-tracing framework for simulating radio propagation in complex 3D environments. In this tutorial, it is used to operate on the scenes generated by the Geo2SigMap scene generation pipeline.

Key capabilities include:

* Fully-differentiable propagation modeling.
* Support for custom material properties.
* Configurable transmitter and receiver deployments (radiation patterns, position, orientation).
* Integration with system-level simulations and machine learning workflows
